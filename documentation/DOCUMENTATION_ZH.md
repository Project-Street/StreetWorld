# StreetWorld 中文文档

[English](DOCUMENTATION_EN.md)

StreetWorld 是一个自动驾驶闭环仿真平台。驾驶策略接收相机、车辆状态等观测，输出轨迹或控制量，在仿真中驱动车辆。
